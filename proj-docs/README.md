# PosterKit

A browser-based editorial image editor with three canvas modes — inspired by music art cards, magazine covers, and gallery-wall aesthetics. Upload a photo, pick a mode, customize every element, and export as PNG, JPG, or PDF.

## Canvas Modes

### Editorial Poster
The original mode. A structured poster anatomy inspired by music art cards and Red Bull editorial photography.

```
│  EVENT LABEL        │           │  EVENT LABEL      alias-pill  │
│                     │           │                               │
│   [ PHOTO AREA ]    │           │      [ PHOTO AREA ]           │
│                     │           │                               │
│  CAR / SUBJECT      │           │  tracklist · details · tags   │
│  Caption text here  │           │                               │

│  Label   Value      │           │             ───────────────── │

```

### Magazine Cover
Full-bleed photo with magazine typography overlaid. Four layout variants, eight built-in templates.

**Layouts:** Standard · Forbes · Vogue · Wired

**Templates:** Forbes · The Times · TIME · Vogue · Nat Geo · Rolling Stone · Wired · The Economist

Each template sets fonts, accent color, vignette, grain, tint, and magazine-specific fields (masthead, cover lines, pull quote, ticker strip, etc.).

### Annotated Photo
A clean photo canvas with draggable floating text annotations — handwriting-style labels you can place anywhere on the image.

## Features

- Upload any photo (JPG, PNG, WEBP) — drag-drop or click
- Portrait or landscape layout (editorial mode)
- Inline editing of all text directly on the canvas
- Customize palette dots (3–6), accent color, display + body fonts
- Detail grid with drag-to-reorder rows
- Vignette, grain, and tint overlays
- 10 editorial visual templates + 8 magazine templates
- AI import: paste a JSON preset generated by an AI agent
- Export as PNG (2×), JPG (2×), or PDF (3×, A4)

## Quick Start

```bash
git clone https://github.com/yourname/posterkit
cd posterkit
npm install
npm run dev
```

Open http://localhost:5173

## Export

- **PNG** — lossless, best for sharing digitally
- **JPG** — compressed, smaller file size
- **PDF** — print-ready, A4 portrait or landscape
